## 코테를 위한 파이썬 기본 문법

Appendix A에 실린 파이썬 문법을 살짝 훑어보고, 몰랐던 사실을 위주로 기록

### 1. 자료형 (수, 리스트)

 * **수**: round (실수형 데이터, 반올림위치 - 1) -> 안 쓰면 소수점 첫째자리
 * **리스트 (배열) - 테이블**
   * 크기가 N인 1차원 리스트 초기화 -> a = [0] * n (n개)
   * 인덱싱 & 슬라이싱
   * 컴프리헨션 -> 2차원 리스트 초기화 (특정 크기의 2차원 리스트 초기화시) -> array = [[0] * m for _ in range(n)]
   * 관련 메서드 및 시간 복잡도:
     * append(): O(1)
     * sort(), sort(reverse=True), reverse()
     * insert(): O(N)
     * count()
     * remove(): O(N)
   * ex) 특정한 원소를 모두 제거 -> result = [i for i in a if i not in remove_set]

### 2. 자료형 (문자열, 튜플, 사전, 집합) 및 제어문/함수

 * **문자열**
   * 초기화: (") or (') 이용 -> (\)를 이용해서 하나의 문자열로 출력 가능
   * 연산: +로 문자 연결, *시 해당 문자열 반복, 리스트와 동일하게 인덱싱/슬라이싱 가능
 * **튜플** -> 리스트와 달리 ① 한번 선언된 값 변경 X ② 소괄호 () 사용
   * 그래프 알고리즘에 자주 사용 (ex: 다익스트라 최단 경로)
 * **사전(딕셔너리)**
   * Key : Value 쌍을 데이터로 가짐
   * 해시테이블 -> 검색 및 수정이 빠름 (O(1))
   * iterable -> "원소 in 사전" 형태 가능
   * 관련함수: keys() (키 데이터만 리스트로), values() (값 데이터만 리스트로)
 * **집합 (set)**: set(), { }
   * 중복허용 X, 순서 X (인덱싱/슬라이싱 X) O(1)
   * "특정한 데이터가 이미 등장한 적이 있는지 확인"
   * 연산 => 합집합 (|), 교집합 (&), 차집합 (-)
   * 함수 -> add() (단일), update() (여러개), remove()
 * **2. 조건문** -> 다 아는 내용
 * **3. 반복문** -> "
 * **4. 함수**
   * def 함수명(매개변수):
   * 실행할 소스코드
   * return 반환값 (존재 or 존재 X)
   * 함수 내부에서 바깥의 변수 변경시 -> global 변수 선언하기 (내부에서)
   * 지역변수를 따로 안만들고 함수 바깥 변수를 바로 참조
   * lambda가 함수를 편하게 작성 가능

### 3. 주요 알고리즘 및 라이브러리

 * **④ bisect**: 이진탐색 전용, O(logN)
   * "정렬된 배열"에서 특정원소 찾을때 매우 효과적
   * bisect_left(a, x) : 정렬 순서 유지, 리스트 a에 x를 삽입할 가장 왼쪽 인덱스 찾기
   * bisect_right(a, x) : " 가장 오른쪽 인덱스 찾기
   * -> '정렬된 리스트'에서 '값이 특정 범위에 속하는 원소의 개수' 구할때 유용
 * **⑤ Collections**: deque, Counter
   * **deque** : 인덱싱/슬라이싱 X -> 연속적으로 나열된 데이터의 시작 부분이나 끝부분에 데이터 삽입/삭제
     * 스택/큐 자료구조의 대용
     * popleft(), pop() / appendleft(), append()
     * append(), popleft() => 선입선출
   * **Counter** : 등장 횟수를 세는 라이브러리
 * **math**: 수학적인 계산 (팩토리얼, 제곱근, 최대공약수 등)

### 4. 입출력 및 표준 라이브러리

 * **5. 입출력**
   * **5-1 입력**
     * input() -> "문자열"로 입력
     * int(input()) -> "정수"로 입력
     * list(map(int, input().split())) -> 여러개의 데이터를 공백으로 구분해 입력시
       * 순서: 문자열 분리 -> 모든 원소에 int() 적용 -> 공백으로 구분해 리스트화 (데이터가 많지 않다면 list()는 뺌)
     * 입력을 최대한 빠르게 받아야 할 때 -> import sys / sys.stdin.readline().rstrip()
   * **5-2 출력**
     * print() -> 연산자 적용시, 같은 자료형 끼리만 가능
     * -> 아니면 , 로 구분해서 출력
 * **6. 주요 라이브러리 문법, 주의점 (6가지)**
   * 표준라이브러리 : 특정한 프로그래밍 언어에서 자주 사용되는 표준 소스코드를 미리 구현해놓은 라이브러리
   * **① 내장함수**: sum(), min(), max(), eval() (수학 수식이 문자열로 들어올때), sorted() -> key 기준 정렬 가능
   * **② itertools**:
     * permutations: iterable 객체에서 n개의 데이터를 뽑아 순서대로 나열하는 경우의 수
     * combinations: iterable 객체에서 n개의 데이터를 뽑아 순서를 고려 X
     * product: permutations와 같은데, 원소를 중복해서 뽑음
     * combinations_with_replacement: combinations에서 중복해서 뽑음
   * **③ heapq**: 우선순위 큐 구현시 사용
     * 최소 힙 -> O(NlogN) 정렬 가능
     * heapq.heappush(), heapq.heappop()
     * ex) 힙 정렬을 heapq로 구현

### 1. 큰 수의 법칙

수학적인 원리를 적용할 수 있다면, 훨씬 간단하게 풀이할 수 있었다.

일반적인 풀이법

```python

# N, M, K를 공백으로 구분해 입력 받기
n,m,k = map(int,input().split())

# N개의 수를 공백으로 구분해 입력 받기
data = list(map(int,input().split()))

data.sort()

first = data[n-1]
second = data[n-2]

result = 0
count = 0

while True:
    for i in range(k):
        if m == 0:
            break
        result += first
        m -= 1
    if m ==0:
        break
    result += second
    m -= 1

result
```

큰 수가 최대로 더해지고, 그 다음 큰 수가 1번만 더해지는 수열이 반복되는 원리를 이용해 계산

```python
# N, M, K를 공백으로 구분해 입력 받기
n,m,k = map(int,input().split())

# N개의 수를 공백으로 구분해 입력 받기
data = list(map(int,input().split()))

data.sort()

first = data[n-1]
second = data[n-2]

count = int(m / (k+1)) * k
count += m % (k+1)

result = 0
result += (count) * first
result += (m - count) * second

print(result)
```

### 3. 1이 될 때까지

```python
# 나의 풀이 -> //으로 정수형 반환하기, 시간 복잡도 고려하기
n, k = map(int, input().split())

count = 0

while True:
    if n % k == 0:
        n = n / k
    else:
        n -= 1
    count += 1
    if n == 1:
        break
    

count
```


```python
# 답안 예시
n, k = map(int, input().split())
count = 0

while True:
    # 1. N이 K로 나누어 떨어지는 가장 가까운 배수를 한 번에 찾기
    target = (n // k) * k
    
    # 2. 배수가 되기 위해 1을 빼야 하는 횟수를 count에 한 번에 더하기
    count += (n - target)
    n = target
    
    # 3. N이 K보다 작아져서 더 이상 나눌 수 없을 때 반복문 탈출
    if n < k:
        break
        
    # 4. K로 나누기
    n //= k
    count += 1

# 5. 남은 수(n)가 1이 될 때까지 1을 빼는 횟수를 마지막으로 더해주기
count += (n - 1)

print(count)
```

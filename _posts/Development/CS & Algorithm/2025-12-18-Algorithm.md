# 그리디(Greedy) 알고리즘

그리디 알고리즘(Greedy Algorithm, 탐욕법)은 이름 그대로 **"현재 상황에서 지금 당장 좋은 것만 고르는 방법"**을 의미한다. 매 순간 가장 좋아 보이는 것을 선택하며, 나중에 미칠 영향에 대해서는 고려하지 않는 것이 특징이다.

## 1. 그리디 알고리즘의 특징
그리디 알고리즘은 보통 최적 해를 구하는 데 사용되지만, 항상 최적의 결과를 보장하지는 않는다. 하지만 그리디 알고리즘을 적용할 수 있는 문제라면 매우 빠르고 효율적으로 해답을 찾을 수 있다.

- **국소적 최적해(Locally Optimal Solution):** 매 단계에서 최선의 선택을 함으로써 전체적인 최적해에 도달하고자 한다.
- **단순성:** 구현이 간단하고 다른 알고리즘(예: 동적 계획법)에 비해 계산 속도가 빠르다.

## 2. 그리디 알고리즘의 조건
그리디 알고리즘이 항상 최적해를 보장하려면 다음 두 가지 조건을 만족해야 한다.

1.  **탐욕적 선택 조건 (Greedy Choice Property):** 앞의 선택이 이후의 선택에 영향을 주지 않아야 한다.
2.  **최적 부분 구조 (Optimal Substructure):** 문제에 대한 최종 해결 방법은 부분 문제에 대한 최적 해결 방법으로 구성되어야 한다.

## 3. 문제 해결 단계
보통 다음과 같은 흐름으로 문제를 해결한다.

1.  **선택 절차 (Selection Procedure):** 현재 상태에서 최적인 선택을 한다.
2.  **적절성 검사 (Feasibility Check):** 선택한 항목이 문제의 제약 조건을 만족하는지 확인한다.
3.  **해답 검사 (Solution Check):** 문제가 해결되었는지 확인하고, 해결되지 않았다면 다시 선택 절차로 돌아간다.

## 4. 대표적인 예시: 거스름돈 문제
가장 대표적인 예시는 '거스름돈 문제'이다. 500원, 100원, 50원, 10원짜리 동전이 무한히 존재할 때, 손님에게 거슬러 줄 금액이 $N$원이라면 최소한의 동전 개수로 거스름돈을 주는 방법이다.

이 문제는 **"가장 큰 단위의 돈부터 최대한 많이 주는 것"**이 그리디한 해결책이 된다.

```python
n = 1260
count = 0

# 큰 단위부터 차례대로 확인
array = [500, 100, 50, 10]

for coin in array:
    count += n // coin # 해당 화폐로 거슬러 줄 수 있는 동전의 개수 세기
    n %= coin

print(count)
```

## 5. 주의사항 및 한계
그리디 알고리즘은 모든 문제에서 최적해를 찾아주지 않는다. 예를 들어, 위의 거스름돈 문제에서도 화폐 단위들이 서로 배수 관계가 아니라면 그리디 알고리즘으로는 최적해를 구할 수 없다. (예: 500원, 400원, 100원 단위에서 800원을 거슬러 줄 때)

따라서 어떤 문제를 그리디로 풀 때는 **해당 방법이 최적의 결과임을 논리적으로 증명**하는 과정이 매우 중요하다.

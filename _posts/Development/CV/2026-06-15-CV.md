# 환경 구축

AnaConda를 통해 가상환경을 설치하고, 필요한 라이브러리를 다운로드 받았다.

중간에 tensorflow가 설치가 안되서 뭔가 했더니, 사용하던 Python 버전 3.14에 맞는 tensorflow 버전이 없어 다운로드를 받지 못했던 거였다.

그래서 3.12 버전으로 가상환경을 다시 만들고, 나머지 필요한 라이브러리까지 다 받아주었다.

이번 글에서는 OpenCV로 영상을 읽고, 변환하고, 웹캠에서 프레임을 받아오는 기본 기능을 정리해본다.

# 1. OpenCV 예제 : 영상 읽고 표시하기

가장 먼저 폴더에 저장된 영상 파일을 읽고, 윈도우에 디스플레이하는 실습을 진행했다.

여기서 말하는 영상은 동영상이 아니라, `jpg`, `png` 같은 이미지 파일을 의미한다.

OpenCV에서 이미지를 읽으면 생성되는 `img` 객체는 numpy의 `ndarray` 타입을 가진다. 결국 컴퓨터비전에서 다루는 이미지는 픽셀값이 들어있는 배열이라고 생각하면 된다.

```python
import cv2 as cv
import sys

# 영상 파일을 읽어 반환
img = cv.imread('soccer.jpg')

if img is None:
    sys.exit('이미지 파일을 읽을 수 없습니다.')

# 윈도우에 영상 표시
cv.imshow('Image Display', img)

# 키보드가 눌릴 때까지 대기
cv.waitKey()

# 모든 윈도우 닫기
cv.destroyAllWindows()
cv.waitKey(1) # Mac OS에서 창을 완전히 지우도록 유도
```

`cv.imshow()`만 쓰면 이미지가 제대로 뜨지 않고 프로그램이 바로 끝나버릴 수 있다. 그래서 `cv.waitKey()`를 통해 키보드 입력이 들어올 때까지 창을 유지해주어야 한다.

![OpenCV 이미지 표시 결과](/assets/img/cv/chapter2/chapter2-01.png)

## OpenCV 영상 객체 확인

OpenCV의 영상 객체가 정말 numpy 배열인지 확인해보자.

```python
print(type(img))
print(img.shape)
```

```text
<class 'numpy.ndarray'>
(326, 612, 3)
```

출력 결과를 보면 `img`는 `numpy.ndarray`이고, 배열의 형태는 `(326, 612, 3)`이다.

여기서 앞의 두 값은 각각 세로, 가로 크기를 의미하고, 마지막 `3`은 색상 채널을 의미한다.

주의할 점은 OpenCV가 이미지를 **RGB가 아니라 BGR 순서**로 읽는다는 것이다.

```python
# (0, 0) 위치의 화솟값
print(img[0, 0, 0], img[0, 0, 1], img[0, 0, 2])

# (0, 1) 위치의 화솟값
print(img[0, 1, 0], img[0, 1, 1], img[0, 1, 2])
```

```text
69 109 158
74 114 163
```

좌표도 일반적인 수학 좌표처럼 `(x, y)`가 아니라, 배열 기준의 `(y, x)` 형태로 접근한다.

컴퓨터비전에서는 이런 데이터 형태와 좌표 순서를 정확히 이해하는 것이 꽤 중요하다고 느꼈다.

# 2. 영상 형태 변환, 크기 축소

이번에는 BGR 컬러 영상을 채널이 1개뿐인 명암 영상으로 변환하고, 영상 크기를 절반으로 줄여보았다.

OpenCV의 `cvtColor` 함수는 컬러 이론에 기반해 BGR 영상을 명암 영상으로 변환한다.

$$ I = \text{round}(0.299 \times R + 0.587 \times G + 0.114 \times B) $$

사람의 눈은 초록색 계열에 더 민감하기 때문에, 단순히 세 채널을 평균내는 것이 아니라 `G` 채널에 더 큰 가중치가 들어간다.

```python
# 명암 영상으로 변환
gray = cv.cvtColor(img, cv.COLOR_BGR2GRAY)

# 크기를 절반으로 축소
gray_small = cv.resize(gray, dsize=(0, 0), fx=0.5, fy=0.5)

# 영상을 파일에 저장
cv.imwrite('soccer_gray.jpg', gray)
cv.imwrite('soccer_gray_small.jpg', gray_small)

cv.imshow('Color image', img)
cv.imshow('Gray image', gray)
cv.imshow('Gray image small', gray_small)

cv.waitKey()
cv.destroyAllWindows()
```

`cv.resize()`에서 `dsize=(0, 0)`으로 두고 `fx`, `fy`를 각각 `0.5`로 설정하면, 원본 영상의 가로와 세로를 절반으로 줄일 수 있다.

![명암 영상 변환 결과](/assets/img/cv/chapter2/chapter2-02.png)

오, 실제로 컬러 이미지가 명암 이미지로 잘 바뀐 것을 볼 수 있었다.

# 3. 웹캠에서 비디오 읽기

이번에는 이미지 파일이 아니라 웹캠을 통해 입력되는 동영상을 읽어보았다.

동영상은 결국 프레임 이미지가 아주 빠르게 이어지는 구조이다. 그래서 OpenCV에서는 웹캠으로부터 프레임을 한 장씩 읽고, 그 프레임을 계속 화면에 띄우는 방식으로 동영상을 표시한다.

```python
# 맥북 웹캠과 연결 시도
cap = cv.VideoCapture(0)

if not cap.isOpened():
    sys.exit("카메라 연결 실패")

while True:
    # 프레임 획득
    ret, frame = cap.read()

    if not ret:
        print('프레임 획득에 실패하여 루프를 나갑니다.')
        break

    # 얻은 프레임 한 장씩 디스플레이
    cv.imshow('Video display', frame)

    key = cv.waitKey(1)
    if key == ord('q'):
        break

cap.release()
cv.destroyAllWindows()
```

`cv.VideoCapture(0)`에서 숫자 `0`은 기본 카메라를 의미한다. 웹캠이 여러 개 연결되어 있다면 숫자를 바꿔가며 다른 카메라를 선택할 수 있다.

핵심은 `while True` 반복문 안에서 `cap.read()`를 계속 호출한다는 것이다. 이렇게 프레임을 한 장씩 받아오고, `cv.imshow()`로 계속 갱신하면 영상처럼 보이게 된다.

![웹캠 프레임 표시 결과](/assets/img/cv/chapter2/chapter2-03.png)

직접 웹캠 화면이 뜨는 걸 보니까 꽤 신기했다. 이미지 한 장을 읽는 것과 크게 다르지 않은 방식으로 비디오까지 다룰 수 있다는 점이 OpenCV의 장점인 것 같다.

## 비디오에서 수집한 영상 이어 붙이기

이번에는 웹캠에서 원하는 순간의 프레임을 저장하고, 저장한 프레임을 가로로 이어 붙였다.

```python
import numpy as np

cap = cv.VideoCapture(0, cv.CAP_AVFOUNDATION)

if not cap.isOpened():
    sys.exit('카메라 연결 실패')

frames = []

while True:
    ret, frame = cap.read()

    if not ret:
        print('프레임 획득에 실패하여 루프를 나갑니다.')
        break

    cv.imshow('Video display', frame)

    key = cv.waitKey(1)

    if key == ord('c'):
        frames.append(frame)
    elif key == ord('q'):
        break

cap.release()
cv.destroyAllWindows()

if len(frames) > 0:
    imgs = frames[0]

    for i in range(1, min(3, len(frames))):
        imgs = np.hstack((imgs, frames[i]))

    cv.imshow('collected images', imgs)
    cv.waitKey()
    cv.destroyAllWindows()
```

`c` 키를 누르면 현재 프레임이 `frames` 리스트에 추가되고, `q` 키를 누르면 웹캠 입력을 종료한다.

이후 `np.hstack()`을 이용해 최대 3장의 프레임을 수평 방향으로 이어 붙였다.

![웹캠 프레임 이어 붙이기](/assets/img/cv/chapter2/chapter2-04.png)

출력된 배열 형태를 확인해보면 다음과 같다.

```python
print(len(frames))
print(frames[0].shape)
print(type(imgs))
print(imgs.shape)
```

```text
3
(1080, 1920, 3)
<class 'numpy.ndarray'>
(1080, 5760, 3)
```

프레임 한 장의 크기가 `(1080, 1920, 3)`이고, 세 장을 가로로 이어 붙였기 때문에 최종 결과의 가로 길이는 `1920 * 3 = 5760`이 되었다.

# 4. 그래픽 기능과 사용자 인터페이스 만들기

컴퓨터비전에서는 영상 위에 도형을 그리거나 글씨를 넣어야 할 때가 많다.

예를 들어 얼굴 인식 결과를 네모 박스로 표시하거나, 표정을 인식했다면 어떤 표정인지 텍스트로 알려주는 경우가 있다.

OpenCV에서는 이런 GUI 기능도 기본적으로 제공한다.

- `rectangle` : 직사각형
- `line` : 직선
- `polylines` : 다각형
- `circle` : 원
- `ellipse` : 타원
- `putText` : 텍스트 문자열

## 영상에 도형 그리고 글씨 쓰기

먼저 이미지 위에 직사각형과 텍스트를 직접 그려보았다.

```python
img = cv.imread('rezero.png')

if img is None:
    sys.exit('이미지 없음')

# 직사각형 그리기
cv.rectangle(img, (125, 5), (235, 165), (0, 0, 255), 2)

# 텍스트 추가
cv.putText(
    img,
    'Shaula',
    (130, 25),
    cv.FONT_HERSHEY_SIMPLEX,
    0.7,
    (255, 0, 0),
    2
)

cv.imshow('Draw', img)

cv.waitKey()
cv.destroyAllWindows()
```

![도형과 텍스트 그리기](/assets/img/cv/chapter2/chapter2-05.png)

직사각형을 그릴 때는 왼쪽 위 모서리 좌표와 오른쪽 아래 모서리 좌표를 직접 지정해야 한다.

그런데 여기서 바로 드는 생각이 있었다.

> 그러면 내가 원하는 곳에 만들려면 좌표를 일일이 알아야 하나?

다행히 그럴 필요는 없다. 마우스 이벤트를 이용하면 직접 클릭한 위치에 도형을 그릴 수 있다.

## 마우스 클릭한 곳에 직사각형 그리기

마우스 이벤트를 처리하려면 콜백 함수를 등록해야 한다.

```python
img = cv.imread('rezero.png')

if img is None:
    sys.exit('이미지 없음')

def draw(event, x, y, flags, param):
    # 마우스 좌클릭 시 빨간 사각형 생성
    if event == cv.EVENT_LBUTTONDOWN:
        cv.rectangle(img, (x, y), (x + 75, y + 75), (0, 0, 255), 2)

    # 마우스 우클릭 시 파란 사각형 생성
    elif event == cv.EVENT_RBUTTONDOWN:
        cv.rectangle(img, (x, y), (x + 100, y + 100), (255, 0, 0), 2)

    cv.imshow('Drawing', img)

cv.namedWindow('Drawing')
cv.imshow('Drawing', img)

cv.setMouseCallback('Drawing', draw)

while True:
    if cv.waitKey(1) == ord('q'):
        cv.destroyAllWindows()
        break
```

![마우스 클릭으로 직사각형 그리기](/assets/img/cv/chapter2/chapter2-06.png)

처음에는 콜백 함수라는 개념이 조금 낯설었다.

보통 프로그램은 위에서 아래로 정해진 순서에 따라 명령어를 실행한다. 그런데 마우스 클릭은 언제 발생할지 알 수 없다.

그래서 콜백 함수는 **이벤트가 발생했을 때 실행할 함수를 미리 등록해두는 방식**이라고 이해했다.

즉, 함수를 만들어두었다고 바로 실행되는 것이 아니라, 마우스 클릭 같은 이벤트가 발생할 때 OpenCV가 해당 함수를 호출해주는 구조이다.

## 드래그로 원하는 크기의 사각형 그리기

클릭 위치에 고정된 크기의 사각형을 그릴 수는 있었지만, 원하는 크기로 조절하려면 드래그를 써야 한다.

구현 방식은 단순하다.

- 마우스를 누른 순간의 좌표를 저장
- 마우스를 뗀 순간의 좌표를 읽음
- 두 좌표를 기준으로 직사각형을 그림

```python
img = cv.imread('rezero.png')

if img is None:
    sys.exit('이미지 없음')

def draw(event, x, y, flags, param):
    global ix, iy

    # 좌클릭 시 직사각형 시작점 기록
    if event == cv.EVENT_LBUTTONDOWN:
        ix, iy = x, y

    # 좌클릭을 뗄 때 시작점과 끝점을 기준으로 직사각형 그리기
    elif event == cv.EVENT_LBUTTONUP:
        cv.rectangle(img, (ix, iy), (x, y), (0, 0, 255), 2)

    cv.imshow('Drawing', img)

cv.namedWindow('Drawing')
cv.imshow('Drawing', img)

cv.setMouseCallback('Drawing', draw)

while True:
    if cv.waitKey(1) == ord('q'):
        cv.destroyAllWindows()
        break
```

드래그가 되니까 원하는 영역을 잡기가 훨씬 쉬워졌다.

# 5. 페인팅 기능 만들기

마지막으로 마우스가 이동한 궤적을 따라 페인팅하는 기능을 만들어보았다.

물체를 따라 오려내거나, 특정 영역을 직접 표시해야 하는 경우 이런 방식이 필요할 수 있다.

코드 골격 자체는 앞에서 만든 직사각형 드래그 기능과 거의 비슷하다.

```python
img = cv.imread('rezero.png')

if img is None:
    sys.exit('이미지 없음')

# 페인팅 설정
brush_size = 5
left_color = (255, 0, 0)   # 파랑
right_color = (0, 0, 255)  # 빨강

def painting(event, x, y, flags, params):
    # 좌클릭 시 파란색, 우클릭 시 빨간색
    if event == cv.EVENT_LBUTTONDOWN:
        cv.circle(img, (x, y), brush_size, left_color, -1)
    elif event == cv.EVENT_RBUTTONDOWN:
        cv.circle(img, (x, y), brush_size, right_color, -1)

    # 좌클릭하고 드래그 시 파란색, 우클릭하고 드래그 시 빨간색
    elif event == cv.EVENT_MOUSEMOVE and flags == cv.EVENT_FLAG_LBUTTON:
        cv.circle(img, (x, y), brush_size, left_color, -1)
    elif event == cv.EVENT_MOUSEMOVE and flags == cv.EVENT_FLAG_RBUTTON:
        cv.circle(img, (x, y), brush_size, right_color, -1)

    cv.imshow('Painting', img)

cv.namedWindow('Painting')
cv.imshow('Painting', img)

cv.setMouseCallback('Painting', painting)

while True:
    if cv.waitKey(1) == ord('q'):
        cv.destroyAllWindows()
        break
```

여기서 `cv.circle()`의 마지막 인자에 `-1`을 넣으면 원 내부가 채워진다.

그리고 `EVENT_MOUSEMOVE`와 `EVENT_FLAG_LBUTTON`, `EVENT_FLAG_RBUTTON`을 함께 사용하면, 마우스를 누른 상태로 움직이는 동안 계속 원을 찍어 페인팅처럼 보이게 만들 수 있다.

# 정리

이번 실습을 통해 OpenCV의 기본적인 입출력과 GUI 기능을 훑어보았다.

정리해보면 다음과 같다.

- OpenCV 이미지는 결국 `numpy.ndarray` 형태의 배열이다.
- OpenCV는 색상 채널을 RGB가 아니라 BGR 순서로 다룬다.
- 이미지 좌표는 배열 기준이므로 `(y, x)` 순서로 접근한다.
- `cv.waitKey()`는 단순 대기가 아니라 OpenCV 창을 유지하고 키보드 입력을 받는 중요한 역할을 한다.
- 동영상은 프레임 이미지를 반복적으로 읽어와 표시하는 구조로 이해할 수 있다.
- 마우스 콜백을 이용하면 사용자의 클릭, 드래그, 이동 이벤트에 맞춰 인터랙티브한 기능을 만들 수 있다.

처음에는 그냥 이미지를 띄우는 정도라고 생각했는데, 웹캠 입력과 마우스 이벤트까지 연결해보니 OpenCV가 단순 이미지 처리 라이브러리라기보다 컴퓨터비전 실습을 위한 기본 도구에 가깝다는 느낌이 들었다.

다음에는 영상에서 관심 영역을 직접 지정하거나, 실제 물체를 검출하는 쪽으로 이어서 공부해보려 한다.

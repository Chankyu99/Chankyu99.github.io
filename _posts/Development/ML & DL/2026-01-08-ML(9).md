## 시계열 데이터 특징 추출

시계열 데이터는 기술 통계학지표, 비선형성과 복잡도 지표, 기록 압축 지표 등등 각종 지표를 가진다.

그러면 `robot_execution` 데이터셋을 활용해 `tsfresh` 라이브러리를 통해 시계열 데이터를 요약하는 통계량을 쉽게 추출해보자.


```python
# 라이브러리 설치 
!pip install tsfresh

# 데이터 로드
from tsfresh.examples.robot_execution_failures import download_robot_execution_failures, load_robot_execution_failures
download_robot_execution_failures()
```

독립변수 `timeseries`는 데이터셋의 feature이고, 종속변수 `y`는 True, False로 되어있는 이진 분류 문제로 정의된다.

`tsfresh` 라이브러리를 이용해 특징을 추출하고 데이터를 대치(impute)하여 특징 행렬로 변환한다.

```python
# 독립변수, 종속변수 정의
timeseries, y = load_robot_execution_failures()

# 특징 추출(feature extraction)
from tsfresh import extract_features
extracted_features = extract_features(timeseries, column_id="id", column_sort="time")
```

추출 단계에서 단순 평균, 최대값 뿐만 아니라 푸리에변환, 엔트로피, 복잡도 등 수리적/통계적 특징을 모두 계산해버려 컬럼 수가 늘어난다.

차원의 저주로 인해 과적합의 우려가 있으니, 추려놓은 후보군에서 설명을 잘하는 주요 특징만 남겨내자.

```python
# 데이터 대치 (impute)
from tsfresh import impute
impute(extracted_features)

# 특징 행렬 반환(select_features)
from tsfresh import select_features
features_filtered = select_features(extracted_features, y)
```

특징 추출 단계에서 데이터의 변동성이 없다면 표준편차가 0이되어 일부 데이터가 결측치가 되거나 이상치가 되어버린다.

`impute`를 통해 해당 컬럼의 평균 혹은 중앙값으로 대치한다. 이로써 시계열 데이터가 전처리 되었다.

유의미한 특징을 추출하기 위해 `select_features`를 사용해 주요 컬럼 후보군을 남기고 나머지 특징을 버린다.

이때 내부적으로 각 특징과 종속변수 사이의 통계적 유의성을 검정하는데, 다중 검정 시 발생하는 제1종 오류의 비율을 통제하는 Benjamini-Yekutieli를 이용한다.

간단하게 말하자면 여러 개의 특징으로 인해 검정할 가설에 대한 P-value를 오름차순으로 정렬하고,

각 순위에 따른 임계값을 계산하고 비교해 가장 큰 순위를 찾아 1순위부터 해당 순위까지의 가설들을 통계적으로 유의미하다고 결론하는 논리이다.

이를 통해 필터링한 값들을 확인해보면 중요한 특징만 살아남아 컬럼 수가 감소한 데이터를 얻을 수 있다.


특징 행렬에서 남은 특징을 파악하면 해당 도메인의 인사이트를 알아낼 수 있고, 패턴의 성격을 파악할 수 있다.

```python

# 힘 센서(F), 토크 센서(T)의 특징 개수 파악 

F_count = []
T_count = []

for col in features_filtered.columns:
    if col.startswith('F'):
        F_count.append(col)
    elif col.startswith('T'):
        T_count.append(col)

print("F_count : ", len(F_count))
print("T_count : ", len(T_count))
print("------------------------")

if len(F_count) > len(T_count):
    print("F가 T보다 중요하다.")
else:
    print("T가 F보다 중요하다.")
```
_해당 데이터셋을 통해 힘 센서가 토크 센서보다 중요하다는 것을 알 수 있었다._


## 시계열 데이터 분류

이제 시게열 데이터에서 중요한 특징을 추출할 수 있으니, 분류 모델링을 해보자.

데이터셋 업로드까지는 이전과 같고, 해당 데이터셋을 가공하기 위한 함수를 정의하면 다음과 같다.

```python
def custom_classification_split(X, y, test_size = 0.3):
    num_true = int(y.sum() * test_size)             # 고장난(True) 로봇 중 6마리(21 * 0.3)을 테스트로 사용
    num_false = int((len(y) - y.sum()) * test_size) # 정상(True) 로봇 중 20마리((88-21) * 0.3)을 테스트로 사용
    

    # 테스트 데이터 셋 생성
    id_list = y[y==False].head(num_false).index.to_list() + y[y==True].head(num_true).index.to_list()
    
    y_train = y[id_list]
    y_test = y.iloc[id_list].sort_index()
    X_train = X[~X['id'].isin(id_list)]
    X_test = X[X['id'].isin(id_list)]

    return X_train, X_test, y_train, y_test


# 커스텀 함수 적용 후 데이터셋 변화 확인

X_train, X_test, y_train, y_test = custom_classification_split(timeseries, y)

print(X_train)
print(y_train)
print("------------------------")
print(X_test)
print(y_test)
```


이제 특징을 추출해보자. 앞서 추출 시 컬럼 리스트를 보면 엔트로피, 푸리에변환 등 조금 난해한 통계량이 포함되어 너무 많은 정보가 포함되어있어 정보 활용이 쉽지 않았다.

최소한의 특징만을 사용해 가볍게 테스트를 진행할 수 있는 `MinimalFCParameters`를 사용해보자.

```python
from tsfresh.feature_extraction.settings import MinimalFCParameters

settings = MinimalFCParameters()

minimal_features = extract_features(X_train,
                                    column_id="id",
                                    column_sort="time",
                                    default_fc_parameters=settings)

minimal_features_test = extract_features(X_test,
                                    column_id="id",
                                    column_sort="time",
                                    default_fc_parameters=settings)

```

추출된 특징을 살펴보면 총합, 중앙값, 평균 등 알기 쉬운 정보들로 구성된 것을 알 수 있다.

일부 특징(여기서는 `F_x__sum_values`, `T_z__maximum`)을 시각화를 통해 더 자세히 알아보면 다음과 같다.

```python
plt.subplot(2,1,1)
plt.plot(minimal_features_train['F_x__sum_values'])
plt.subplot(2,1,2)
plt.plot(minimal_features_train['T_z__maximum'])
plt.show()
```


_x축은 시간(t)이 아니라 로봇의 ID임을 명심하자._

자, 우선 독립변수 $x$가 0.5보다 크거나 같으면 1, 그렇지 않으면 0으로 분류하는 로지스틱 회귀 모델을 만들어보자.

```python
from sklearn.linear_model import LogisticRegression

lgr = LogisticRegression()

lgr.fit(minimal_features_train, y_train)

lgr.score(minimal_features_test, y_test) # score 확인 

classification_report(y_test, lgr.predict(minimal_features_test), target_names =['true','false'], output_dict=True) # score만으로는 모델의 성능 보장이 어려우니 여러 평가지표를 분석
```

결과를 통해 완벽히 분류를 해낸 것을 알 수 있다. (데이터셋 특성이 완벽히 분류되게 되어있음)

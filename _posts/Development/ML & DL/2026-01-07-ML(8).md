## 정상성(Stationarity)

그럼 과거의 분석을 미래에 적용하려는데, 시간과 무관한 특성을 가진 시계열 데이터가 가장 이상적인 데이터라고 생각 할 수 있다.

이 데이터를 우리가 정상성(stationarity)이 있다고 판단할 수 있다.

정상성이란 시간에 무관하게 시계열이 일정한 성질을 띠는 것, 즉 통계적 특성이 변하지 않는 것을 의미한다.

정상성은 두 가지로 분류할 수 있는데, 강정상성과 약정상성으로 구분한다.

- 강정상성 : 모든 적률(통계학에서 평균, 분산, 왜도, 첨도)가 시간과 무관하게 일정
- 약정상성 : 시간에 따라 일정한 평균, 분산, 공분산을 가지는 확률과정

## 정상성 판단

정상성의 개념을 대충 알았으니 삼성전자 주가 그래프를 보고 정상성을 판단해보자.

우선 관측값과 추세 그래프를 지켜보면, 시간이 흐를수록 주가의 중심 위치(평균)과 등락 폭(분산)이 변하는 것을 알 수 있다. 

![4](/assets/img/ML(8)_3.png)

따라서 두 그래프는 비정상성(non-stationarity)을 띠고 있다고 볼 수 있다.

반대로 잔차 그래프를 보자. 

![5](/assets/img/ML(8)_4.png)

기준선을 중심으로 주가가 급락한 사례를 제외하면 진폭이 어느정도 일정하게 유지됨을 알 수 있다.

따라서 잔차 그래프는 정상성(stationarity)을 띠고 있다고 볼 수 있다.

여기까지는 우리가 시각적으로만 정상성을 판단했다. 하지만 시각적으로만 판단하기에는 이르다.

통계적인 검증을 통해 좀 더 확실하게 정상성을 판단할 수 있는 두 가지 검증방법이 존재한다.

눈대중은 위험하다: 통계적 검증 (ADF & KPSS)시각적 판단은 직관적이지만 주관적일 수 있다.

### 1. ADF 검정 (Augmented Dickey-Fuller Test)

ADF 검정은 시계열 데이터가 **"비정상(Non-stationary)"**이라는 전제를 깔고 시작한다. 

데이터 안에 추세를 만드는 '단위근(Unit Root)'이 존재한다고 강력하게 의심하는 것이다.

단위근과 추세의 관련한 [글](https://blog.naver.com/deniro33/222850888571)을 읽어보면 도움이 많이 될 것이다.

- 귀무가설($H_0$): 데이터는 비정상이다. (단위근이 존재한다.)
- 대립가설($H_1$): 데이터는 정상이다.
- 판단 기준: P-value가 **0.05 이하(Low)**여야 한다. 

### 2. KPSS 검정 (Kwiatkowski-Phillips-Schmidt-Shin Test)

반면, KPSS 검정은 데이터가 **"정상(Stationary)"**이라는 믿음을 가지고 시작한다. 

특정 추세를 제외하면 데이터가 안정적이라고 가정하는 것이다.

- 귀무가설($H_0$): 데이터는 정상이다.
- 대립가설($H_1$): 데이터는 비정상이다
- 판단 기준: P-value가 **0.05 초과(High)**여야 한다. 

서로 결이 다른 이 두 가지를 같이 사용해 통계적으로 유의미함을 강력하게 주장 할 수 있는 교차검증(Cross-Check)의 느낌을 기억하자.

"하나만 쓰면 되지 왜 헷갈리게 반대인 두 가지를 다 쓸까?"라는 의문이 들 수 있다. 

그 이유는 각 검정 방법이 잡아내는 '비정상성'의 종류가 다르기 때문이다.

단위근과 추세의 관계를 언급한게 기억이 나는가? ADF는 불규칙하게 움직이는 확률적 추세(Stochastic Trend)를 잘 잡아낸다.

KPSS는 일정한 방향으로 움직이는 확정적 추세(Deterministic Trend) 유무를 판단하는 데 강점이 있다.

따라서 두 검정의 결과를 교차 검증해야 데이터의 진짜 성격을 알 수 있다. 

가장 이상적인 **'완벽한 정상성'**은 ADF는 P-value가 낮고(기각), KPSS는 P-value가 높을(채택) 때 확보된다.

## 정상성을 부여하는 법

그렇다면 정상성을 데이터에 직접 부여할 수 있으면 되지 않을까? 정상성을 부여하는 법을 알아보자. 

우선 정상성을 부여하기 위해 평균과 분산을 건드릴 것이다.

정상성을 가지기 위해 평균과 분산을 일정하게 만들어 줄 수 있는데, 분산의 경우 로그 변환을 사용할 수 있다.

평균의 경우 회귀, 평활, 차분 등 여러가지 방법을 사용할 수 있다.

그러면 비정상성을 가지는 삼성전자의 관측값을 원본 데이터와 차분한 데이터의 검정 테스트 결과를 비교해보자.

<details>
<summary>코드 참고</summary>
<div markdown="1">

```python
from statsmodels.tsa.stattools import adfuller, kpss
import pandas as pd
import warnings

# 경고 메시지 무시 (KPSS 실행 시 자주 뜸)
warnings.filterwarnings("ignore")

def check_stationarity(timeseries):
    print("--------------------------------------------------")
    # 1. ADF Test
    adf_result = adfuller(timeseries)
    adf_p = adf_result[1]
    
    # 2. KPSS Test
    # regression='c'는 상수(Constant)만 고려, 'ct'는 추세(Trend)까지 고려
    kpss_result = kpss(timeseries, regression='c', nlags="auto")
    kpss_p = kpss_result[1]

    print(f"[ADF P-value]: {adf_p:.4f}", end=" -> ")
    if adf_p < 0.05:
        print("정상 (Stationary)")
        adf_pass = True
    else:
        print("비정상 (Non-Stationary)")
        adf_pass = False

    print(f"[KPSS P-value]: {kpss_p:.4f}", end=" -> ")
    if kpss_p > 0.05:
        print("정상 (Stationary)")
        kpss_pass = True
    else:
        print("비정상 (Non-Stationary)")
        kpss_pass = False
        
    print("\n=> [종합 판단]: ", end="")
    if adf_pass and kpss_pass:
        print("완벽한 정상 시계열입니다. (Best)")
    elif not adf_pass and not kpss_pass:
        print("완벽한 비정상 시계열입니다. (차분 필요)")
    elif not adf_pass and kpss_pass:
        print("추세 정상 시계열입니다. (추세 제거 필요)")
    else:
        print("차분 정상 시계열입니다. (차분 필요)")
    print("--------------------------------------------------")

# 위에서 만든 df_monthly(월봉)와 df_diff(차분 데이터)가 있다고 가정

print("\n1. 원본 데이터 (Close) 검증 결과")
check_stationarity(df_monthly)

print("\n2. 1차 차분 데이터 (Diff) 검증 결과")
# 차분 데이터의 첫 번째 결측치 제거 후 입력
check_stationarity(df_monthly.diff().dropna())
```

엥? 원본 데이터는 둘 다 비정상으로 옳게 판정했는데, 1차 차분(Differencing) 데이터에서는 KPSS와 ADF의 결과가 갈렸다.

이론적으로는 차분을 하면 정상성이 확보되어야 하는데 왜 이런 결과가 나왔을까? 

원인은 두 가지였다.

1. 데이터의 개수(Sample Size) 부족 

- 월봉으로 데이터를 합치다 보니 5년 치라 해도 점이 60개밖에 되지 않아 통계적 신뢰도가 떨어졌다.

2. 구조적 충격(Structural Break)
- 2024년 하반기 경영진의 반성문 사태 등 외부 충격으로 인해 변동성(분산)이 급격히 커진 구간을 ADF 모델이 '비정상'으로 인식한 것이다.

이 문제를 해결하기 위해 두 가지 기법을 적용했다.

<details>
<summary>코드 참고</summary>
<div markdown="1">

```python
import numpy as np
import yfinance as yf
import pandas as pd
from statsmodels.tsa.stattools import adfuller, kpss
import warnings

warnings.filterwarnings("ignore")

# 1. 데이터 다시 가져오기 (주봉 '1wk'로 변경하여 데이터 개수 확보)
# 5년치 주봉 데이터는 약 260개 정도 됩니다.
df = yf.download('005930.KS', period='5y', interval='1wk')

# 2. 로그 변환 (Log Transform)
# 가격의 절대적인 크기가 아니라 '변동률'로 바꾸어 분산을 안정시킵니다.
df['Log_Close'] = np.log(df['Close'])

# 3. 차분 (Differencing)
# 로그 데이터에 차분을 적용 -> 이것이 곧 '주간 수익률'이 됩니다.
df_log_diff = df['Log_Close'].diff().dropna()

# 4. 검정 함수 (재사용)
def check_stationarity_simple(timeseries):
    # ADF Test
    adf_result = adfuller(timeseries)
    adf_p = adf_result[1]
    
    # KPSS Test
    kpss_result = kpss(timeseries, regression='c', nlags="auto")
    kpss_p = kpss_result[1]

    print(f"데이터 개수: {len(timeseries)}개")
    print(f"[ADF P-value]: {adf_p:.4f} ({'정상' if adf_p < 0.05 else '비정상'})")
    print(f"[KPSS P-value]: {kpss_p:.4f} ({'정상' if kpss_p > 0.05 else '비정상'})")
    
    if adf_p < 0.05 and kpss_p > 0.05:
        print("=> 결과: ★완벽한 정상 시계열입니다★")
    else:
        print("=> 결과: 아직 비정상 성질이 있습니다.")

print(">>> [로그 변환 + 주봉 차분 데이터 검증] <<<")
check_stationarity_simple(df_log_diff)
```

본래라면 정상 시계열 데이터로 처리되어야 하지만 앞서 말한 이상치로 인해 아직 비정상 성질이 남아있는 걸 확인할 수 있다.

그렇지만 ADF 검정을 통해 P-value가 0.0에 수렴할 정도로 추세가 강하게 제거되었다고 간주하고 분석을 진행해도 된다.

왜냐하면 금융 데이터의 경우 변동성이 매우 심한 이분산성이 특징이기 때문에 KPSS까지 완벽하게 만족하는 경우가 드물기 때문이다.

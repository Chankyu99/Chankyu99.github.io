## 정상성(Stationarity)

그럼 과거의 분석을 미래에 적용하려는데, **시간과 무관한 특성**을 가진 시계열 데이터가 가장 이상적인 데이터라고 생각 할 수 있다.

이 데이터를 우리가 **정상성(stationarity)**이 있다고 판단할 수 있다.

정상성이란 시간에 무관하게 시계열이 일정한 성질을 띠는 것, 즉 **통계적 특성이 변하지 않는 것**을 의미한다.

정상성은 두 가지로 분류할 수 있는데, **강정상성**과 **약정상성**으로 구분한다.

- **강정상성** : 모든 **적률(통계학에서 평균, 분산, 왜도, 첨도)**이 시간과 무관하게 일정
- **약정상성** : 시간에 따라 일정한 평균, 분산, 공분산을 가지는 확률과정

## 정상성 판단

정상성의 개념을 대충 알았으니 삼성전자 주가 그래프를 보고 정상성을 판단해보자.

우선 **관측값**과 **추세** 그래프를 지켜보면, 시간이 흐를수록 주가의 중심 위치(평균)과 등락 폭(분산)이 변하는 것을 알 수 있다. 

![4](/assets/img/ML(8)_3.png)

따라서 두 그래프는 **비정상성(non-stationarity)**을 띠고 있다고 볼 수 있다.

그럼 **잔차** 그래프는 어떨까? 

![5](/assets/img/ML(8)_4.png)

평균은 0으로 일정하여 추세적 성질은 제거되었으나, 24년 하반기 충격 등으로 인해 분산이 일정하지 않은(**이분산성**) 한계가 있다. 

따라서 **잔차** 그래프도 **비정상성(non-stationarity)**을 띠고 있다고 볼 수 있다.

추후 모델링을 통해 가격의 방향은 예측할 수 있으나, 급작스러운 변동성 확대까지는 완벽히 예측하기 어려울 수 있음을 인지해야 한다.

이러한 불확실한 예측을 통계적으로 검정하는 **2가지 방법**이 존재한다. 각각의 방법은 전제가 다르므로 잘 알아두자.

### 1. ADF 검정 (Augmented Dickey-Fuller Test)

ADF 검정은 시계열 데이터가 **"비정상(Non-stationary)"**이라는 전제를 깔고 시작한다. 

데이터 안에 추세를 만드는 **'단위근(Unit Root)'**이 존재한다고 강력하게 의심하는 것이다.

단위근과 추세의 관련한 [글](https://blog.naver.com/deniro33/222850888571)을 읽어보면 도움이 많이 될 것이다.

- 귀무가설($H_0$): 데이터는 비정상이다. (단위근이 존재한다.)
- 대립가설($H_1$): 데이터는 정상이다.
- 판단 기준: P-value가 **0.05 이하(Low)**여야 한다. 

### 2. KPSS 검정 (Kwiatkowski-Phillips-Schmidt-Shin Test)

반면, KPSS 검정은 데이터가 **"정상(Stationary)"**이라는 믿음을 가지고 시작한다. 

특정 추세를 제외하면 데이터가 안정적이라고 가정하는 것이다.

- 귀무가설($H_0$): 데이터는 정상이다.
- 대립가설($H_1$): 데이터는 비정상이다
- 판단 기준: P-value가 **0.05 초과(High)**여야 한다. 

서로 결이 다른 이 두 가지를 같이 사용해 통계적으로 유의미함을 강력하게 주장 할 수 있는 **교차검증(Cross-Check)**의 느낌을 기억하자.

**"하나만 쓰면 되지 왜 헷갈리게 반대인 두 가지를 다 쓸까?"**라는 의문이 들 수 있다. 

그 이유는 각 검정 방법이 잡아내는 '비정상성'의 종류가 다르기 때문이다.

단위근과 추세의 관계를 언급한게 기억이 나는가? ADF는 불규칙하게 움직이는 **확률적 추세(Stochastic Trend)**를 잘 잡아낸다.

KPSS는 일정한 방향으로 움직이는 **확정적 추세(Deterministic Trend)** 유무를 판단하는 데 강점이 있다.

따라서 두 검정의 결과를 교차 검증해야 데이터의 진짜 성격을 알 수 있다. 

가장 이상적인 **'완벽한 정상성'**은 ADF는 P-value가 낮고(기각), KPSS는 P-value가 높을(채택) 때 확보된다.

## 정상성을 부여하는 법

정상성을 가지지 않은 시계열 데이터의 미래를 예측하는 것은 사실상 불가능에 가깝다. 

그렇다면 정상성을 가지게 할 수 있는 방법이 없을까?

정상성을 가지게 할 수 있는 방법은 시계열 데이터의 평균 혹은 분산을 건드려주는 것이다.

평균을 먼저 건드리면 이따가 언급할 차분 과정에서 음수가 발생할 수 있어 로그 변환이 불가능하거나 분산 패턴이 왜곡될 우려가 있기 때문이다. 

### 분산을 일정하게 : 변환(Transformation)

주가 그래프를 통해 시계열 데이터가 이분산성이라는 특징을 가진다는 것을 앞서 느꼈다. 

문제가 되는 이분산성을 해결하기 위해 데이터 스케일을 조정하는 **변환(Transformation)**과정을 거쳐준다.

대표적인 변환과정으로 **로그 변환(Log Transformation)**과 **제곱근 변환(Square Root Transformation)**이 있다.

로그 변환의 경우, 가장 많이 쓰이며 자연로그($$\ln$$)를 사용해 데이터의 분산을 일정하게 한다.

로그 변환을 사용하면, 주가를 분석할 때 가격($$P_t$$)을 그대로 쓰지 않고 로그 수익률($$\ln P_t - \ln P_{t-1}$$)을 쓰게 된다.

제곱근 변환의 경우, 로그 보다는 약하지만 데이터에 0이 포함된 경우 사용한다.

### 평균을 일정하게 : 차분(Differencing)

시계열 데이터는 시간($t$)이 흐를 수록 평균이 계속 변화하는 성질을 가지고 있다. 

평균이 일정하지 않다면 "미래에도 평균적으로 이러할 것이다"라는 예측이 불가능 하다.

따라서 시계열 데이터의 평균을 일정하게 하기 위해 **차분(Differencing)** 과정을 거쳐준다.

$t$ 시간의 관측값 $y_t$를 $t-1$ 시간의 관측값 $y_{t-1}$에서 뺀 값이 차분한 값이라고 한다.

이때, 특정 주기($m$)의 패턴을 지우는 걸 목표로 한다면, 해당 주기만큼 떨어진 값($y_{t-m}$)을 빼줄 수도 있다. (계절 차분이라고 한다.)

변환과 차분 과정을 통해 정상성을 부여할 수 있나는 것을 알게 되었으니, 그러면 비정상성을 가지는 삼성전자의 관측값을 원본 데이터와 차분한 데이터의 검정 테스트 결과를 비교해보자.

```python
from statsmodels.tsa.stattools import adfuller
import matplotlib.pyplot as plt

# ADF 테스트 결과를 보기 좋게 출력하는 함수
def adf_test(timeseries):
    print("Results of Dickey-Fuller Test:")
    dftest = adfuller(timeseries, autolag='AIC')
    dfoutput = pd.Series(dftest[0:4], index=['Test Statistic','p-value','#Lags Used','Number of Observations Used'])
    print(dfoutput)
    print(f"Result: {'정상 시계열임 (Stationary)' if dfoutput['p-value'] < 0.05 else '비정상 시계열임 (Non-Stationary)'}")
    print("--------------------------------------------")

# 1. 원본 데이터 검증 (아마 비정상일 것임)
print("[1. 원본 데이터(Close) ADF Test]")
adf_test(df_monthly)

# 2. 1차 차분 (Differencing) 적용
# diff(): 현재 값 - 바로 이전 값
df_diff = df_monthly.diff().dropna()

# 3. 차분된 데이터 검증 (정상성을 획득했을 것임)
print("[2. 1차 차분 데이터(Diff) ADF Test]")
adf_test(df_diff)

# 4. 차분된 데이터 시각화
plt.figure(figsize=(12, 4))
plt.plot(df_diff, label='1차 차분 데이터', color='purple')
plt.title('Differenced Data (Stationary)')
plt.axhline(0, color='black', linestyle='--')
plt.legend()
plt.show()
```

어, 이론적으로는 차분을 하면 정상성이 확보되어야 하는데 차분을 적용해도왜 이런 결과가 나왔을까? 원인은 두 가지였다.

먼저, **데이터의 개수(Sample Size)가 너무 부족하다는 것이다**.

월봉으로 데이터를 합치다 보니 5년 치라 해도 점이 60개밖에 되지 않아 통계적 신뢰도가 떨어졌다.

그리고 **구조적 충격(Structural Break)**이 있었다.

2024년 하반기 경영진의 반성문 사태 등 외부 충격으로 인해 변동성(분산)이 급격히 커진 구간을 ADF 모델이 '비정상'으로 인식한 것이다.

이 문제를 해결하기 위해 월봉을 주봉으로 바꾸어 **데이터 개수를 증강(60 -> 260개 정도)**하고 **로그 변환을 통해 변동성을 안정**시켰다.

그리고 특정 기간에 변동이 치솟은 이상치를 제어하는 **윈저화(Winsorization)**를 적용했다.

윈저화(Winsorization)는 통계 데이터 내 극단적인 값을 **특정 백분위수**로 재설정해 이상치를 제거하는 방법이다.

```python
import yfinance as yf
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import koreanize_matplotlib
from statsmodels.tsa.stattools import adfuller, kpss
import matplotlib.ticker as mticker
import warnings

warnings.filterwarnings("ignore")

# ==============================================================================
# 1단계: 데이터 전처리 및 정상성 확보 (솔루션 적용)
# ==============================================================================

# 1. 주봉(Weekly) 데이터 가져오기 (데이터 개수 확보)
stock_code = '005930.KS'
print(f"[{stock_code}] 데이터 다운로드 중...")
df = yf.download(stock_code, period='5y', interval='1wk')

# 2. 로그 변환 (Log Transformation)
df['Log_Close'] = np.log(df['Close'])

# 3. 로그 수익률 계산 (차분)
df_log_diff = df['Log_Close'].diff().dropna()

# 4. 이상치 제어 (Winsorization)
lower_limit = df_log_diff.quantile(0.05)
upper_limit = df_log_diff.quantile(0.95)
df_clean = df_log_diff.clip(lower=lower_limit, upper=upper_limit)

print("\n>>> [정상성 검증 결과 (해결책 적용 후)]")
# 검증 함수
def check_stationarity(timeseries):
    adf_p = adfuller(timeseries)[1]
    kpss_p = kpss(timeseries, regression='c', nlags="auto")[1]
    print(f"ADF P-value: {adf_p:.4f} (0.05 미만이면 정상)")
    print(f"KPSS P-value: {kpss_p:.4f} (0.05 초과면 정상)")
    
    if adf_p < 0.05 and kpss_p > 0.05:
        return True
    return False

if check_stationarity(df_clean):
    print("=> 결과: ★정상성(Stationarity) 확보 성공! 모델링을 시작합니다.★")
else:
    print("=> 결과: 완벽하진 않지만, ADF 통과로 모델링을 진행합니다.")

# ==============================================================================
# 2단계: 시각화 (Visualizing the Transformation)
# ==============================================================================
fig, axes = plt.subplots(3, 1, figsize=(14, 12), sharex=False)

# 1. 원본 주가 (Original Price)
axes[0].plot(df.index, df['Close'], label='원본 주가 (Close)', color='black')
axes[0].set_title('1. 원본 주가 (비정상 시계열: 추세 존재)', fontsize=14, fontweight='bold')
axes[0].set_ylabel('주가 (원)')
axes[0].grid(True, alpha=0.3)
axes[0].legend(loc='upper left')
# Y축 원화 포맷
axes[0].yaxis.set_major_formatter(mticker.FuncFormatter(lambda x, p: f'{int(x):,}원'))

# 2. 로그 차분 데이터 (Log Returns - Before Clipping)
axes[1].plot(df_log_diff.index, df_log_diff, label='로그 수익률 (Clipping 전)', color='tab:orange')
axes[1].set_title('2. 1차 차분 데이터 (정상성 실패: 2024년 변동성 폭발 확인)', fontsize=14, fontweight='bold')
axes[1].set_ylabel('수익률')
axes[1].axhline(0, color='black', linestyle='--', linewidth=1)
# 잘려나갈 부분(Outlier) 표시
axes[1].axhline(upper_limit, color='red', linestyle=':', label='상위 5% 임계값 (절단 기준)')
axes[1].axhline(lower_limit, color='red', linestyle=':', label='하위 5% 임계값 (절단 기준)')
axes[1].grid(True, alpha=0.3)
axes[1].legend(loc='upper left')

# 3. 이상치 제어 후 데이터 (Winsorized - Final Data)
axes[2].plot(df_clean.index, df_clean, label='Winsorized 데이터 (최종 학습용)', color='tab:blue')
axes[2].set_title('3. 이상치 제어 후 (정상성 확보: 분산 안정화)', fontsize=14, fontweight='bold')
axes[2].set_ylabel('보정된 수익률')
axes[2].axhline(0, color='black', linestyle='--', linewidth=1)
axes[2].grid(True, alpha=0.3)
axes[2].legend(loc='upper left')

plt.tight_layout()
plt.show()
```

1차 차분에서 주가가 급변하는 특정 구간에서 **이상치**가 발생함을 눈으로 확인할 수 있었고,

이를 윈저화를 통해 이상치를 제거한 후의 시각화를 보면 분산이 이전보다 안정화되어 **정상성을 확보**할 수 있었다.

그러나 주가 데이터 특성상 완벽히 변동을 붙잡았다고는 하기에는 어렵다. 

왜냐하면 **KPSS 검정에서 P-value가 0.05 미만**이 아니기 때문이다.

추가적인 전처리 과정을 더 진행할 것인가 아니면 이대로 모델링을 시작할 것인가를 결정하는 것은 **데이터 사이언티스트의 판단**이 된다.

## 시계열 데이터 EDA

시계열 데이터 간의 상관관계를 파악하는 EDA과정에서 가장 중요한 것은 바로 **자기상관성(Autocorrelation)**이다.

이제 **ACF**와 **PACF**라고 부르는 두 가지 방법론을 통해 자기상관성을 시각화하여 

**시차(Lag)에 따른 관계를 파악해 추후 ARIMA 모델링에서 최적의 파라미터를 결정한다.**

**ACF**는 특정 두 시점 사이의 **모든** 자기상관관계를 나타내는 것이다. 

즉, 두 시점($t$와 $t-1$) 사이의 자기상관관계 뿐만 아니라 그 사이에 있는 다른 시점들의 영향까지 모두 포함된 상관계수라고 보면 된다.

**PACF**는 ACF와는 다르게 특정 두 시점 사이만의 자기상관관계를 나타내는 것이다.

주의해야 할 점은 상관관계 분석을 통해 단순히 추세가 비슷하다고 해서 인과관계가 있다고 **허위 상관(Spurious Correlation)**으로 판단하지 말아야 한다는 것이다.

앞서 우리가 주가 데이터를 다루는 과정에서 차분과 로그 변환을 진행한 것은 이러한 허위 상관을 제거하고 데이터의 진짜 관계를 보기 위한 필수적인 전처리라고 할 수 있다.

그러면 삼성전자의 주가 데이터를 **ACF**와 **PACF**로 시각화해보자.

```python
import yfinance as yf
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import koreanize_matplotlib
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
import warnings

warnings.filterwarnings("ignore")

# ==============================================================================
# 1. 데이터 준비 (앞선 단계와 동일)
# ==============================================================================
stock_code = '005930.KS'
df = yf.download(stock_code, period='5y', interval='1wk')
df['Log_Close'] = np.log(df['Close'])
df_log_diff = df['Log_Close'].diff().dropna()

# 이상치 제어 (Winsorization) -> 최종 정상성 데이터 생성
lower_limit = df_log_diff.quantile(0.05)
upper_limit = df_log_diff.quantile(0.95)
df_clean = df_log_diff.clip(lower=lower_limit, upper=upper_limit)

# ==============================================================================
# 2. ACF & PACF 그리기
# ==============================================================================
fig, axes = plt.subplots(1, 2, figsize=(16, 6))

# (1) ACF 함수 그리기 (MA 모델의 q값 추정용)
# lags=20: 과거 20주(약 5개월)까지만 상관관계를 보겠다는 의미
plot_acf(df_clean, ax=axes[0], lags=20, title='ACF (Autocorrelation): q(MA)값 탐색', color='blue', vlines_kwargs={"colors": "blue"})
axes[0].set_xlabel('Lag (지연 시점)')
axes[0].set_ylabel('상관계수')
axes[0].grid(True, alpha=0.3)

# (2) PACF 함수 그리기 (AR 모델의 p값 추정용)
plot_pacf(df_clean, ax=axes[1], lags=20, title='PACF (Partial Autocorrelation): p(AR)값 탐색', color='red', vlines_kwargs={"colors": "red"}, method='ywm')
axes[1].set_xlabel('Lag (지연 시점)')
axes[1].set_ylabel('상관계수')
axes[1].grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

$x$축의 시작지점은 자기 자신과의 상관관계를 나타내기 때문에 1이 되어 높게 치솟은 걸 알 수 있다.

그래프에 집중해야 할 부분은 **음영 부분**과 **상관관계 값의 분포**를 보는 것이다.

두 그래프 모두 대부분의 상관관계 값이 **음영 내**에 분포 되어 있는 것을 알 수 있다.

이는 Lag0(자기자신과의 상관관계)를 제외한 모든 **Lag가 임계값(통계학에서 95% 신뢰구간)내에 머무른다는 뜻이다.**

그러므로 결국 현재 데이터가 과거의 데이터와 **뚜렷한 선형 관계를 가지지 못한다는 것이다.** (이를 **랜덤 워크(Random Walk)**라고 부른다.)

앞서 ACF, PACF를 통해 얻은 정보로 ARIMA 모델링을 진행한다고 했는데,

모델링에 필요한 **파라미터 값**이 각 그래프에서 음영 밖으로 튀어나온 **Lag의 상관관계 값**을 기준으로 결정되기 때문이다.

시각적인 판단으로 모델링에 필요한 파라미터를 결정할 수 있지만, 요즘은 기술이 좋아져 최적의 파라미터를 알아서 결정해주는 **Auto ARIMA**를 통해 모델링을 진행할 수 있다.
